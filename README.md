### 💻 How to Run This Project 

### 1. Install Visual Studio Code
Download and install:  
https://code.visualstudio.com/

### 2. Install Python
Download Python:  
https://www.python.org/downloads/

⚠️ IMPORTANT:
- Make sure to check **"Add Python to PATH"** during installation

### 3. Install Python Extension in VS Code
- Open VS Code  
- Go to Extensions (left sidebar)  
- Search for **Python (by Microsoft)**  
- Click Install  

### 4. Open the Project Folder
- Open VS Code  
- Click **File → Open Folder**  
- Select your **Cyber Project folder**

### 5. Open Terminal in VS Code
- Click **Terminal → New Terminal**

### 6. Install Required Libraries
Run:

pip install flask scikit-learn pandas numpy

If that doesn’t work:

python -m pip install flask scikit-learn pandas numpy


### 7. Select Python Interpreter
- Press **Ctrl + Shift + P**  
- Type **Python: Select Interpreter**  
- Choose your installed Python version  

### 8. Run the Application
In the terminal:

python App.py

or:

py App.py

### 9. Open the Website
Go to:
http://127.0.0.1:5000
